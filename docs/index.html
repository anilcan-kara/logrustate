🔄 logrustate
GitHub →

Modern logrotate,
written in Rust.

Drop-in compatible with logrotate.conf syntax + supports modern TOML configuration with a real dry-run mode.

cargo install logrustate

🔄 Drop-in Compatible

Reads existing logrotate.conf files without requiring syntax modifications.

📄 Modern TOML Config

Write clean, structured log rotation configurations using standard TOML format.

🐛 Real Dry-Run Mode

Run logrustate --debug to preview rotations without altering files.

🗜️ Compression & Archival

Automatic gzip, bzip2, and xz compression for rotated log files.
